# Wheel of Samsara

An isometric action-RPG set in a Mahayana Buddhist universe. A monk descends through the six realms of rebirth (Deva, Human, Asura, Animal, Preta, Naraka) to reach Nirvana. Vampire Survivors-style auto-combat meets Diablo 2-style classes, skill trees, gear, quests and bosses.

**Play:** https://drummondworking-max.github.io/Samsara/

Works on desktop (fullscreen) and phone. Progress is saved in your browser.

## Build from source
`python3 build.py` concatenates `src/` into `dist/`. The playable file is `index.html`.
